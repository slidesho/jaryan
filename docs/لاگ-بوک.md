## دور ۷ — گره‌های تازه (۲۸ آبان ۱۴۰۵)
- مالک خواست همه‌ی بخش «گره‌های تازه» اضافه شود. [فعلی، تأیید مالک]
- موتور: اجرای جداگانه برای هر آیتم (`server/src/engine/meta.ts`: `PER_ITEM_TYPES`)، تلاش دوباره (تا ۵ بار، مکث تا ۱۰ ثانیه) و «ادامه با خطا» (خطا در فیلد `error` آیتم؛ برای گره‌های دسته‌ای روی همه‌ی آیتم‌ها). شرط قبلاً فقط آیتم اول را می‌سنجید؛ اصلاح شد. [فعلی]
- منطق و داده (`data-nodes.ts`): فیلتر (خروجی عبور/rest)، سوییچ تا ۱۰ حالت + «دیگر»، مرتب‌سازی پایدار، ادغام (پشت‌سرهم/تک‌آیتم/یکتا)، حلقه روی فهرست (`splitOut`، سقف ۱۰۰۰) و جمع‌کردن، CSV (خواندن با گیومه/BOM، نوشتن با محافظ تزریق فرمول اکسل). [فعلی]
- تقویم شمسی (`jalali.ts`، الگوریتم جلالی): تبدیل دوطرفه، نام ماه و روز هفته، افزودن روز، «اکنون» به وقت تهران؛ رفت‌وبرگشت ۲۰ ساله روز‌به‌روز تست شد و ۱۴۰۵/۰۸/۲۷ = ۲۰۲۶-۱۱-۱۸. [فعلی]
- محرک‌ها: زمان‌بندی کرون (`cron.ts`، تجزیه‌گر خودنویس، پیش‌فرض Asia/Tehran، هر دقیقه حداکثر یک اجرا) و دریافت پیام بات تلگرام/بله با `getUpdates` (`server/src/api/triggers.ts`). فقط برای گردش‌کار «فعال»؛ پیام‌های قبل از فعال‌سازی رد می‌شوند؛ حالت اجرا «زمان‌بندی» و «پیام ربات» در تاریخچه. [فعلی]
- بله `getUpdates`: بر اساس سازگاری با API تلگرام نوشته شد؛ در مستندات بله فقط `sendMessage` خوانده شده بود و با بات واقعی تست نشد. [باز]
- ایمیل SMTP (`nodemailer`)، گوگل شیت با حساب سرویس (JWT/REST: خواندن، افزودن، به‌روزرسانی)، PostgreSQL (`pg`)، MySQL (`mysql2`)، هوش مصنوعی سازگار با OpenAI (خلاصه، دسته‌بندی، پاسخ، دلخواه): `service-nodes.ts`. [فعلی]
- SQL: عبارت `{{ }}` در دستور جایگذاری نمی‌شود و رد می‌شود؛ مقدارها فقط با `$1`/`؟` و فیلد «مقدارها» (جلوگیری از تزریق SQL). سقف ۱۰۰۰ ردیف و مهلت اجرا. [فعلی]
- دکمه‌های بات (درون‌پیامی و کیبورد پاسخ) برای تلگرام و بله، با اعتبارسنجی. [فعلی]
- گره کد (`code-node.ts`): فرایند جدا با `--permission` (بدون فایل/فرزند/ورکر)، بدون ساخت کد از رشته، محیط خالی، ۵ ثانیه، ۶۴ مگابایت، سقف ورودی/خروجی ۱ مگابایت؛ کد در context جدا و فقط JSON از مرز رد می‌شود. تست‌ها: حلقه‌ی بی‌پایان، بمب حافظه، خروجی حجیم، و ۷ روش فرار با زنجیره‌ی constructor همگی ناموفق. نیاز به Node 22+. [فعلی]
- گره کد (ملغا‌شده ← ۲۸ آبان ۱۴۰۵: طرح کانتینر + isolated-vm)؛ جایگزین: فرایند جدا + مدل مجوز Node. [ملغا‌شده ← ۲۸ آبان ۱۴۰۵]
- شبکه‌ی گره کد: مدل مجوز Node شبکه را نمی‌بندد؛ فقط اگر `unshare` لینوکس باشد فرایند بدون شبکه اجرا می‌شود (در این محیط تست شد که ابزار هست). ویندوز و مک بدون ضمانت. برای میزبانی عمومی کانتینر لازم است. [باز]
- رابط: دسته‌های دینامیک (سوییچ، فیلتر)، فیلد چندخطی، «تنظیمات پیشرفته‌ی اجرا» (تلاش دوباره، ادامه با خطا)، گروه‌های تازه‌ی پالت. در نسخه‌ی نمایشی (مرورگر) گره‌های ایمیل، شیت، پایگاه‌داده، هوش مصنوعی و کد پیام «در نسخه‌ی نمایشی کار نمی‌کند» می‌دهند. [فعلی]
- بسته‌سازی: `bundle` با banner برای `require` و هدف Node 22؛ از روی بسته‌ی ساخته‌شده اتصال واقعی SMTP/PostgreSQL/MySQL (خطای رد اتصال درست) و گره کد اجرا شد. [فعلی]
- تست: ۸۵ تست خودکار؛ تست مرورگر: سوییچ ۳ دسته، ذخیره‌ی تلاش دوباره و ادامه با خطا، بدون خطای کنسول. [فعلی]
- ساخته نشد: ایتا و آموت (مستندات نیست)، دریافت ایمیل (IMAP)، محرک تغییر گوگل شیت، فایل Excel (xlsx؛ CSV جایگزین است). [باز]
- تست نشده با سرویس واقعی: SMTP، شیت، گوگل، PostgreSQL، MySQL (فقط اتصال)، هوش مصنوعی، getUpdates بله/تلگرام، کاوه‌نگار. [باز]
- هشدار npm audit روی vitest/vite (فقط ابزار توسعه، نه بسته‌ی تحویلی). [باز]
- SSRF در گره HTTP و نشانی سرویس هوش مصنوعی هنوز باز است؛ ورود/احراز هویت ندارد؛ ذخیره‌ی JSON موقت؛ مخزن هنوز عمومی. [باز]
