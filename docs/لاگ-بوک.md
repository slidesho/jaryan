## دور ۵ — نسخه‌ی قابل تست (۲۷ آبان ۱۴۰۵)
- مالک خواست همه‌ی کارها بدون پرسش انجام شود و خروجی قابل تست بدهم. [فعلی، تأیید مالک]
- API سرور (`server/src/api`): گردش‌کارها (ساخت، خواندن، ویرایش، حذف)، اجرای دستی، وب‌هوک `/webhook/<شناسه>`، تاریخچه‌ی اجرا، کاتالوگ گره‌ها. فقط با ماژول‌های خود Node. [فعلی]
- ذخیره‌سازی فعلاً فایل JSON (`data/data.json`) است، نه PostgreSQL. [موقت]
- محرمانه‌ها (توکن بات، کلید کاوه‌نگار) در پاسخ API با «__SECRET__» پنهان می‌شوند و با ذخیره‌ی دوباره حفظ می‌شوند. در فایل data هنوز رمزنگاری‌نشده‌اند. [موقت]
- امنیت نسخه‌ی آزمایشی: فقط روی 127.0.0.1، بررسی Host (جلوگیری از DNS rebinding)، الزام `application/json` برای تغییرها (جلوگیری از CSRF)، سقف حجم بدنه ۱ مگابایت، سقف ۱۰۰ گره و ۳۰۰ اتصال، مهلت ۳۰ ثانیه برای درخواست‌های بیرونی. ورود/احراز هویت ندارد. [موقت]
- گره HTTP هنوز به نشانی‌های داخلی (localhost و شبکه‌ی خصوصی) هم وصل می‌شود؛ پیش از استقرار عمومی باید مسدود شود (SSRF). [باز]
- رابط (`web/`): React + React Flow، فارسی و راست‌چین، فونت وزیرمتن محلی، جهت جریان راست به چپ. صفحه‌ی فهرست، ویرایشگر بوم، پنل تنظیم گره، ورودی آزمایشی، نتیجه‌ی هر گره، تاریخچه، فعال‌سازی وب‌هوک. [فعلی]
- طراحی برند و پالت نهایی نشده؛ رنگ‌ها موقتی‌اند. بوم طراحی جدا ساخته نشد و رابط مستقیم در کد ساخته شد (انحراف از اصل «طراحی ملاک است»). [باز]
- بسته‌ی آزمایشی: `scripts/package-test.sh` ← `dist-test/jaryan-test.zip`؛ فقط Node 20+ لازم دارد (`start.bat` / `start.sh`). [فعلی]
- تست: ۳۰ تست خودکار؛ تست مرورگر واقعی (Chrome) از روی zip پاک بدون خطای کنسول: نمونه، اجرا، تغییر شرط، وب‌هوک، تاریخچه، ذخیره‌ی گره، پنهان بودن توکن بعد از بارگذاری دوباره. [فعلی]
- تست نشد: ویندوز و `start.bat`، ویرایشگر روی موبایل، پیام واقعی به بله/تلگرام/کاوه‌نگار، حذف گره و اتصال با کلید Delete، کارکرد روی مرورگرهای غیر Chrome. [باز]
