# سند تعریف پروژه: جریان (نام موقت)

وضعیت: پیش‌نویس اول، ۲۷ آبان ۱۴۰۵ (۱۸ نوامبر ۲۰۲۶). برچسب‌ها طبق لاگ‌بوک: [فعلی] [موقت] [باز].

## ۱. مسئله
کسب‌وکارها و افراد فارسی‌زبان برای وصل کردن ابزارهایشان به هم (پیامک، پیام‌رسان‌های ایرانی، شیت، پایگاه داده، وب‌هوک) یا باید کد بنویسند یا از ابزارهای خارجی مثل n8n/Zapier استفاده کنند که رابط فارسی ندارند، به سرویس‌های ایرانی (کاوه‌نگار، آموت، بله، ایتا) وصل نمی‌شوند و روی سرور ایران سخت نصب می‌شوند. [فعلی، تأیید مالک]

## ۲. مخاطب
- مالکان کسب‌وکار و بازاریاب‌هایی که کد نمی‌نویسند.
- توسعه‌دهنده‌ها و تیم‌های فنی کوچک که اتوماسیون روی سرور خودشان می‌خواهند.

## ۳. ارزش و تمایز
1. رابط کامل فارسی، راست‌چین، اعداد فارسی، تقویم شمسی.
2. اتصال‌های بومی: بله، ایتا، کاوه‌نگار، آموت (علاوه بر تلگرام و ایمیل).
3. اجرا روی سرور ایران بدون وابستگی به سرویس بیرونی.
4. ویرایشگر بصری گره و اتصال (گراف) با خروجی هر گره قابل مشاهده.

## ۴. هسته‌ی MVP [فعلی، تأیید مالک: ۱۸ نوامبر ۲۰۲۶]
### ۴.۱ موتور
- گردش‌کار = گراف جهت‌دار از گره‌ها؛ هر گره ورودی و خروجی JSON دارد.
- ترتیب اجرا، شاخه (شرط)، ادغام شاخه‌ها، حلقه روی فهرست.
- اجرای هر گردش‌کار ثبت می‌شود (ورودی/خروجی هر گره، وضعیت، زمان، خطا).
- صف اجرا با Redis؛ تلاش دوباره با قاعده‌ی قابل تنظیم؛ مهلت اجرا.
- بیان‌گر داده بین گره‌ها (مثل `{{ گره.فیلد }}`).

### ۴.۲ گره‌های اولیه
| دسته | گره |
|---|---|
| تریگر | وب‌هوک، زمان‌بند (کرون و بازه)، دستی |
| پایه | درخواست HTTP، شرط، تبدیل داده، کد (جاوااسکریپت ایزوله)، تاخیر |
| پیام‌رسان | تلگرام، بله، ایتا |
| پیامک و ایمیل | کاوه‌نگار، آموت، SMTP |
| داده | گوگل شیتس، PostgreSQL/MySQL |

### ۴.۳ رابط
- فهرست گردش‌کارها، ویرایشگر بوم، تاریخچه‌ی اجرا، مدیریت اعتبارنامه‌ها (کلید و توکن، رمزنگاری‌شده)، فعال/غیرفعال کردن.

### ۴.۴ حساب و دسترسی
- ورود با پیامک (شماره‌ی ایرانی) و ایمیل (شماره‌ی خارجی). فضای کاری، نقش‌ها: مالک، ویرایشگر، بیننده.

## ۵. خارج از MVP
بازار گره‌های جامعه، گره‌های هوش مصنوعی، خوشه‌ی چندسرور، ورودی/خروجی گردش‌کار به‌صورت قالب، درگاه پرداخت، نسخه‌ی ابری چندمستاجری با صورتحساب.

## ۶. واژه‌نامه [موقت]
| مجاز | ممنوع |
|---|---|
| گردش‌کار | ورک‌فلو |
| گره | نود |
| اتصال | کانکشن (در معنای خط بین گره‌ها)؛ برای حساب بیرونی: «اعتبارنامه» |
| محرک | تریگر |
| اجرا | اگزکیوشن |
| وب‌هوک (نام فنی، استثنا) | — |

## ۷. نقش‌ها
مالک فضای کاری، ویرایشگر، بیننده، ادمین سامانه.

## ۸. موجودیت‌ها (ERD سطح بالا)
`کاربر`، `فضای‌کاری`، `عضویت`، `گردش‌کار`، `نسخه‌ی‌گردش‌کار`، `گره`، `اتصال‌بین‌گره`، `اعتبارنامه` (رمزنگاری‌شده)، `اجرا`، `اجرای‌گره`، `محرک‌وب‌هوک`، `محرک‌زمان‌بند`.

## ۹. قواعد کسب‌وکار (عددها پارامتر ادمین)
- سقف زمان اجرا، سقف تعداد تلاش دوباره، سقف حجم ورودی وب‌هوک، مدت نگهداری تاریخچه‌ی اجرا: همه پارامتر ادمین؛ پیش‌فرض‌ها در فاز طراحی.
- اعتبارنامه هرگز در خروجی API یا لاگ نمایش داده نمی‌شود.
- گره «کد» در ایزوله‌ی بدون دسترسی شبکه و فایل اجرا می‌شود.

## ۱۰. پشته‌ی فنی [فعلی، تأیید مالک]
Node.js + TypeScript، PostgreSQL، Redis (صف)، فرانت Vue یا React (انتخاب با تحقیق ویرایشگر گراف، [باز])، ویرایشگر بوم بر پایه‌ی کتابخانه‌ی گراف (مثل Vue Flow یا React Flow، [باز])، Docker برای استقرار.

## ۱۱. برند [باز]
نام، لوگو، پالت و فونت هنوز تعیین نشده‌اند. نام «جریان» و نام مخزن `jaryan` فقط موقتی‌اند.

## ۱۲. پرسش‌های باز
1. نام نهایی محصول و دامنه؟ (پیش‌فرض: «جریان»، موقت)
2. فرانت Vue یا React؟ (پیش‌فرض: Vue، چون Vue Flow ساده‌تر است؛ پس از تحقیق نهایی)
3. مدل ارائه: نصب روی سرور خود مشتری، سرویس میزبانی‌شده، یا هر دو؟ (پیش‌فرض: نصب با Docker؛ سرویس میزبانی‌شده بعد از MVP)
4. مجوز و فروش: کاملاً اختصاصی یا هسته‌ی متن‌باز؟ (پیش‌فرض: اختصاصی)
