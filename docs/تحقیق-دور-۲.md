## ۱. ویرایشگر گراف

| گزینه | یافته | منبع |

| xyflow-vue | پورت تازه‌تر Vue 3 روی همان موتور `@xyflow/system`؛ پروژه‌ی جوان، بدون اطمینان از پایداری | sveltethemes.dev |

| LiteGraph | آخرین پوش اوت ۲۰۲۴؛ کنار گذاشته شد | pistack.xyz |

بررسی نشد: پشتیبانی هر کتابخانه از راست‌به‌چپ. این را در نمونه‌ی آزمایشی کوچک باید تست کرد، چون جهت پورت‌ها و فلش‌ها در بوم مهم است.

**پیشنهاد [باز]:** React + React Flow، چون نگه‌داری فعال‌تر و جامعه‌ی بزرگ‌تری دارد و n8n‌مانندها (Zapier/Retool-مانند) معمولاً روی آن ساخته می‌شوند. اگر ترجیح شما Vue است، Vue Flow هم کار می‌کند ولی بر پایه‌ی نسخه‌ی قدیمی‌تر است. این پیشنهاد با پیش‌فرض قبلی (Vue) فرق دارد و باید شما تصمیم بگیرید.

## ۲. معماری موتور اجرا

- n8n دو حالت دارد: «معمولی» (همه‌چیز در یک پردازه) و «صف» که پردازه‌ی اصلی (رابط، وب‌هوک، زمان‌بندی) کارها را در Redis می‌گذارد و پردازه‌های کارگر اجرا می‌کنند. صف حتماً به PostgreSQL و Redis نیاز دارد. (منابع: مستندات n8n، بلاگ elest.io، activepieces)
- پیشنهاد برای MVP: همین دو حالت را از اول در طراحی نگه داریم؛ نسخه‌ی اول با یک پردازه + BullMQ روی Redis، و کارگرها جداگانه قابل افزودن باشند.
- کلید رمزنگاری اعتبارنامه باید بین همه‌ی پردازه‌ها یکسان باشد (n8n هم همین الزام را دارد؛ منبع: kevinleary.net). کلید در `.env` و هرگز در گیت.
- n8n برای کد کاربر «task runner» بیرونی دارد (`N8N_RUNNERS_MODE=external`)؛ منبع: bigmike.help.

## ۳. اجرای ایمن گره «کد»

- `node:vm`: مستندات Node می‌گوید مکانیزم امنیتی نیست؛ استفاده نشود.
- `vm2`: منسوخ، با چند آسیب‌پذیری گریز از سندباکس؛ استفاده نشود.
- `isolated-vm`: جداسازی واقعی V8، بهتر از vm2، ولی پژوهشگران Endor Labs یک آسیب‌پذیری بحرانی در کد C++ واسط آن گزارش کرده‌اند که می‌تواند به اجرای کد روی میزبان برسد (devops.com). **نتیجه:** به‌تنهایی کافی نیست.
- **پیشنهاد [باز]:** گره کد در یک پردازه‌ی جدا (کانتینر بدون شبکه، با سقف حافظه و زمان، کاربر بدون دسترسی) اجرا شود و درونش از `isolated-vm` استفاده شود. یعنی دو لایه.

## ۴. سرویس‌های ایرانی

| سرویس | وضعیت تحقیق |
|---|---|
| کاوه‌نگار | API رسمی REST دارد (`sms/send`، `verify/lookup`، `account/info` و ...) و SDK نود موجود است. اتصال آسان. (کاوه‌نگار گیت‌هاب، Deno SDK) |
| بله | بات API شبیه تلگرام دارد (ارسال پیام، رسانه، وب‌هوک، دکمه). مستندات رسمی در `docs.bale.ai`؛ من خودِ آن صفحه را باز نکردم و از روی کتابخانه‌های غیررسمی خواندم. |
| ایتا | **یافته‌ی قابل اتکا پیدا نشد.** جستجو فقط ویکی‌پدیا داد. باید مستندات رسمی یا «ایتایار» را از خود شما یا با جستجوی دقیق‌تر بگیریم. [باز] |
| آموت | **یافته‌ی قابل اتکا پیدا نشد.** فقط یک مطلب تبلیغاتی در زومیت آمد. مستندات را باید از پنل آموت شما گرفت. [باز] |

نکته: وب‌سایت Snooto شما قبلاً از کاوه‌نگار به آموت مهاجرت کرده، پس کلید و نمونه‌ی درخواست آموت را می‌توانید از همان پروژه بدهید.

## ۵. نتیجه و قدم بعد
1. تصمیم شما: React Flow یا Vue Flow.
2. تأیید معماری دو لایه برای گره کد.
3. ارسال مستندات ایتا و آموت (یا اجازه‌ی جستجوی بیشتر).
4. بعد از این‌ها: طراحی صفحه‌ها (فهرست گردش‌کار، ویرایشگر، تاریخچه، اعتبارنامه) و سپس اسکلت کد.
